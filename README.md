## About

I work across **frontend, backend, and data**. At Shippify I ship features on the Fleet product — the React microfrontend operators use to onboard and manage drivers. Before that I built data pipelines and reports at MetLife.

I like work that shows up on a real screen: lists that stay consistent under slow APIs, copy that matches the product language, and small UX details that make a dense operations tool easier to use.

Currently studying **Software Engineering at FIAP**.

## What I have been working on

**Shippify · Software Engineer**
- Fleet onboarding: pagination with a page-size selector (15 / 25 / 50), persisted in `localStorage` across onboarding and drivers
- i18n for the same screen (`pt` / `es` / `en`) — operators in Brazil were seeing mixed *applicants* / *aplicantes*; standardized to *motoristas* / *drivers* / *conductores*
- Request races on the applicant list: abort the in-flight fetch and ignore stale responses when page size, filters, or page change before the previous call returns
- Node.js APIs and AWS Lambdas around driver operations

**MetLife · Data Engineer**
- Pipelines and notebooks on **Azure Synapse** with **PySpark**
- Data governance and analytical reports in **Power BI**
- Access management in cloud environments
